# 发布工具文档

- `docs/UIReactTool/Design.md`：工具目标、职责边界和输入规则。
- `docs/UIReactTool/Development.md`：发布包代码结构、依赖和验证边界。
- `docs/UIReactTool/Usage.md`：安装、配置、生成、预览和目标项目验收方法。

发布包根目录包含 `package.json`、`Editor/` 和 `Tests/Editor/`，可使用 Unity Package Manager 的 Git URL 安装。测试项目仍将工具副本放在 `Tools/Assets/UIReactTool`，两份副本的同步方式见发布目录 `README.md`。
